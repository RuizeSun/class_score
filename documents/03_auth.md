# 认证与授权系统

## 概述

系统提供两种认证方式：

1. **PIN码认证** - 6位数字密码
2. **USB密钥认证** - 使用特定U盘自动解锁

## PIN码系统

### 特点

- 设置时需要6位数字
- 使用 UTF-8 字节的十六进制哈希存储
- 设置后无法直接查看，只能重置

### 解锁验证

解锁时支持最长100位的密码输入，只要密码中包含原始6位PIN码即可成功解锁。

**此功能可通过设置开关控制：**

- **开启**：支持最长100位密码输入，只要包含原始6位PIN码即可解锁
- **关闭**：恢复原来的6位精确匹配模式

**验证规则：**

- 输入密码至少需要6位
- 系统会检查输入中任意6位连续子串是否与原始PIN码匹配
- 如果找到匹配的子串，解锁成功
- 例如：原始PIN为 `123456`，输入 `abc123456def` 可以解锁

**设置位置：** 系统设置 → 启用长密码解锁

### 状态

- `isPinSet` - 是否已设置PIN码
- `isUnlocked` - 是否已解锁
- `unlockedByManual` - 是否通过手动方式解锁
- `unlockedByUsb` - 是否通过USB密钥解锁

### 自动锁定规则

- 手动解锁后，10分钟后自动恢复课程表规则
- 如果当前不在课程表时间段内，将自动锁定

### 相关文件

`lib/providers/auth_provider.dart`

## USB密钥系统

### 工作原理

1. 用户选择一个U盘作为密钥盘
2. 系统在U盘根目录创建隐藏文件 `.class_key`
3. 文件内容为加密的令牌
4. 插入U盘时系统自动验证并解锁

### 密钥操作

- **写入密钥** - 在U盘上创建隐藏的密钥文件
- **删除密钥** - 从U盘删除密钥文件（不会删除数据库记录）
- **重命名** - 修改数据库中的标签名

### 检测频率

- 每5秒扫描一次U盘
- 拔出U盘立即锁定

### 相关文件

`lib/providers/auth_provider.dart`

---

## 课程表自动控制

### 规则

- 在课程表时间段内自动解锁
- 不在课程表时间段内自动锁定
- 手动解锁会覆盖此规则，但10分钟后自动恢复

### 当前课程

- 系统始终显示当前正在进行的课程名称
- 即使在锁定状态下也会显示

### 时间规范化

- 自动将输入时间规范化为 `HH:mm` 格式
- 例如：`8:0` → `08:00`，`9:5` → `09:05`

### 相关文件

`lib/providers/auth_provider.dart`

## 窗口行为配置

锁定状态下的窗口行为可通过「个性化」设置页面进行配置：

- **未解锁时允许最小化窗口**：开启后，即使应用处于锁定状态也可以最小化窗口。默认关闭（锁定状态下阻止最小化）。
- **未解锁时允许关闭窗口**：开启后，即使应用处于锁定状态也可以直接关闭窗口。默认关闭（锁定状态下阻止关闭）。

设置存储在 `app_settings` 表中：

- `allow_minimize_locked` - 锁定状态下是否允许最小化（`"true"` / `"false"`）
- `allow_close_locked` - 锁定状态下是否允许关闭（`"true"` / `"false"`）

## 页面结构

- `pages/core/pin_setup_page.dart` - PIN设置页
- `pages/core/unlock_page.dart` - 解锁页

- `pages/dashboard/course_schedule_page.dart` - 课程表页
- `pages/settings/personalization_card.dart` - 个性化设置页（主题色、窗口行为）

## 导航与设置Tab显示

### 显示逻辑

系统根据认证状态控制设置Tab在导航栏中的显示：

- **未解锁状态**：设置Tab不出现在底部导航栏中，用户无法访问设置页面
- **已解锁状态**：设置Tab正常显示在底部导航栏中

### 自动跳转

当用户位于设置Tab页面时上锁，系统会自动跳转到主页：

1. 监听认证状态变化
2. 检测到从已解锁变为已锁定时
3. 检查当前是否在设置页面
4. 如果在设置页面，自动导航回主页

### 设置页面操作权限

由于设置Tab在未解锁时不会显示在导航栏中，设置页面内的所有控件默认处于可用状态，无需额外的 `isUnlocked` 条件判断。这简化了设置页面的开发逻辑。
