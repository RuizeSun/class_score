# 备份与恢复系统

## 概述

系统提供完整的数据库备份和恢复功能，支持自动备份、手动备份和数据导出。

## 备份存储

### 备份位置

```
应用程序目录/backups/
```

### 备份文件命名

格式：`backup_YYYY-MM-DDTHH-MM-SS.db`

### 备份限制

- 最多保留50个备份文件
- 超出限制时自动删除最旧的备份

## 备份类型

### 1. 自动备份

在执行以下操作前自动创建备份：

- 添加/修改/删除小组
- 添加/修改/删除学生
- 添加/修改/删除评分记录
- 添加/修改/删除评分项目

### 2. 手动备份

用户可通过设置页面手动创建备份。

### 3. 操作前备份

在以下操作前自动备份：

- 切换评分周期
- 导入学生数据
- 恢复备份
- 重置数据

## 恢复功能

### 从备份恢复

- 选择已有的备份文件
- 用备份内容覆盖当前数据库
- 重新加载所有数据

### 备份列表

- 按修改时间降序排列
- 显示备份文件信息

## 数据导出/导入

### JSON 导出

导出以下数据为 JSON 格式：

- 小组 (groups)
- 学生 (students)
- 评分记录 (score_records)
- 课程表 (course_schedule)
- 导出时间戳

### JSON 导入

- 先清空现有数据
- 按顺序导入各表数据
- 重新分配自增ID

## 重置功能

### 重置评分记录

- 删除所有评分记录
- 保留学生和小组

### 重置小组

- 删除所有评分记录
- 删除所有学生
- 删除所有小组

### 重置全部

- 删除所有评分记录
- 删除所有学生
- 删除所有小组
- 删除课程表
